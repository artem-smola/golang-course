# CLI tool for fetching information about GitHub repository

## Usage
# Building
```bash
cd cli
go build .
```
# Execution and input
```bash
./cli suvorovrain/golang-course
```

# Alternative input
```bash
./cli suvorovrain golang-course
```

# Output
```bash
golang-course:
        Description: Homework for GoLang course 2026
        Stars      : 0
        Forks      : 28
```
